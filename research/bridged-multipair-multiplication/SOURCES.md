This checkpoint summarizes pinned material; it copies no source code or certificate data.

## Primary mathematical sources

- Original OpenAI integer-multiplication manuscript, immutable pin [adc7f1241b42e322a6451854ab7e4b4c146bf78a](https://redirect.github.com/openai/math/commit/adc7f1241b42e322a6451854ab7e4b4c146bf78a). The read files were README.md, RELATED-WORK.md, VERIFY.md, the Bridge2 role/invocation/certificate files, the WHT challenge, solution wrapper, and B2Gp193Main.lean.
